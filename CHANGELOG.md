# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [0.4.2] — 2026-11-06

### Исправлено
- Сервер виджета автоматически повторяет запуск на прежнем порту и восстанавливается после его освобождения. Очереди и каналы сохраняются, предупреждение снимается автоматически.
- На Linux локальный Spotify управляется через MPRIS: запуск с проверкой трека, пауза, продолжение, громкость и восстановление позиции. Команды Web API, которые возвращали 204 без воспроизведения, для локального режима не используются.
- В «Подключениях» можно отключить локальное управление для работы с удалённым устройством через Web API. Изменение режима применяется после перезапуска.

## [0.4.1] — 2026-11-06

### Исправлено
- Заказ «исполнитель — название» ищется по обоим полям и проверяется на совпадение.
- При отказе из-за повтора или другого лимита заказ больше не заменяется следующей песней из результатов поиска.

## [0.4.0] — 2026-11-06

### Исправлено
- Spotify-заказ считается начатым только после подтверждения воспроизведения нужного трека на выбранном устройстве; принятой команды API больше недостаточно для списания баллов.
- Прямые ссылки YouTube сохраняют выбранное видео и воспроизводятся в OBS без подмены на Spotify.
- «Вернуть очередь» повторно запускает текущий заказ, сохраняя его и ожидающие треки.
- Пустые команды Spotify (пауза, продолжение, громкость) передают `Content-Length: 0`, предотвращая HTTP 411.
- Логи музыки содержат причины отклонения и переходы состояния очереди.

### Добавлено
- Проверка новых версий из GitHub Releases при запуске: окно «Пропустить / Обновить»,
  прогресс загрузки, проверка подписи и перезапуск. Для `.deb`/`.rpm` — переход к релизу.
- Подпись пакетов обновления и публикация `latest.json` в release workflow.

## [0.3.0] — 2026-11-05

### Добавлено
- Анимации во всех встроенных темах виджета «Сейчас играет» и «Очередь»: смена трека,
  новые и сдвигающиеся строки очереди, счётчик, плавный прогресс, появление и скрытие,
  фоновые циклы в стиле темы (диск, блик, развёртка, вспышка, дрейф) — только во время
  воспроизведения, на паузе замирают. При «уменьшении движения» в системе анимаций нет.
- SDK виджета: `data-mode` на `<html>`, помощники `replay`, `show`, `progress`, `list`
  для своих тем (экспериментально, см. docs/themes.md).
- Демо виджета: `DEMO=cycle`, `MODE`, `PROGRESS` для предпросмотра.

## [0.2.0] — 2026-11-04

### Добавлено
- Клонирование голоса на видеокарте NVIDIA (Linux x86_64): GPU-пакет ≈230 МБ
  ставится из «Записей», нужен драйвер 580+, CUDA 13 и cuDNN 9. Быстрый клон ≈2 мин.
- Диагностика: лог `logs/stream-assist.log` с ротацией, кнопка «Открыть папку логов»,
  снимок состояния `GET http://127.0.0.1:<порт>/debug` (без текста чата). См. docs/debugging.md.

### Удалено
- Дообучение голоса на GPU и вкладка «Обучение»: качество заметно хуже клонирования.
  Уже обученные голоса остаются и работают; пакет `voice-lab/trainer/` можно удалить вручную.

## [0.1.0] — 2026-11-04

Первый публичный выпуск.

### Музыка
- Заказ треков за баллы канала Twitch: поиск, ссылки Spotify и YouTube.
- Очередь с перетаскиванием, пропуск, пауза, громкость, возврат очереди после сбоя.
- Воспроизведение через Spotify стримера, YouTube — запасной источник.
- Лимиты зрителей: длительность, повторы, заказов на зрителя.
- Возврат баллов, если трек не сыграл или заказ отклонён.

### Правила
- Явная схема «вид триггера → триггер → действие»: «Заказ трека» ← награда,
  «Озвучка» ← награда или метка в чате.
- Несколько триггеров на действие, награды обходят лимиты действия.
- Награды на Twitch создаются, обновляются и удаляются автоматически;
  выключение триггера даёт доиграть очередь и не принимает новые заказы.
- Перенос настроек со старого формата с резервной копией.

### Озвучка и Voice Lab
- Озвучка текста наград и сообщений чата голосом Supertonic 3 в отдельный источник OBS.
- Voice Lab: записи, клонирование, микшер голосов, рендеры, дообучение на GPU (Linux + NVIDIA; удалено в 0.2.0),
  экспорт и импорт голосов и проектов.

### Виджет и панель
- Виджет OBS «сейчас играет» и «очередь»: встроенные темы и импорт своих из zip,
  добавление источников в OBS одной кнопкой.
- Новая панель: тёмная тема «студийный пульт», боковое меню со статусами сервисов.

### Сборки
- Linux: `.deb`, `.rpm`, `.AppImage`. Windows: `.exe` (NSIS), `.msi`. Без подписи.
