# Обновления приложения

При запуске release-сборки Stream Assist проверяет
`https://github.com/MushroomSquad/stream-assist/releases/latest/download/latest.json`.
Манифест создаёт `tauri-action` и прикладывает к релизу вместе с пакетами и `.sig`.
Черновики и prerelease не предлагаются пользователям. В dev-режиме проверки нет.
Если манифест ещё не опубликован или сеть недоступна, приложение запускается обычно.

Окно новой версии предлагает «Пропустить» (до следующего запуска) и «Обновить».
Загрузка начинается только по нажатию. Подпись проверяет официальный плагин Tauri;
после загрузки приложение ставит награды Twitch на паузу, устанавливает обновление
и перезапускается. Музыка и озвучка при этом прерываются.
Windows использует NSIS-установщик, Linux — замену AppImage. Установки `.deb`/`.rpm`
получают такое же уведомление, но кнопка открывает страницу нужного релиза для
установки нового системного пакета. Настройки и голоса в каталоге данных сохраняются.

## Однократная настройка релизов

Публичный ключ уже записан в `plugins.updater.pubkey` в `src-tauri/tauri.conf.json`.
Соответствующий приватный ключ создан локально в `.local/updater.key` (в `.gitignore`).
Сохраните его резервную копию в надёжном месте: будущие обновления должны
подписываться этим же ключом. В репозиторий приватный ключ не добавляется.

В GitHub → Settings → Secrets and variables → Actions добавьте:

- `TAURI_SIGNING_PRIVATE_KEY`: содержимое `.local/updater.key` целиком.
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`: пароль ключа, если он задан.
  Первоначально созданный ключ имеет пустой пароль, этот секрет можно не добавлять.

Затем увеличьте версии в трёх файлах, как описано в README, и выпустите тег `vX.Y.Z`.
Workflow подпишет пакеты и добавит `latest.json` в черновик релиза. Опубликуйте
черновик после успешной сборки обеих платформ и проверьте, что `latest.json`
содержит `windows-x86_64` и `linux-x86_64` с URL пакетов и подписями.
Первая версия с этим механизмом устанавливается вручную; следующие уже обновляются из неё.

Обычная локальная сборка не требует ключа. Для сборки с подписями:

```sh
TAURI_SIGNING_PRIVATE_KEY="$PWD/.local/updater.key" \
TAURI_SIGNING_PRIVATE_KEY_PASSWORD='' \
TWITCH_CLIENT_ID=… npm run tauri build -- --config '{"bundle":{"createUpdaterArtifacts":true}}'
```

Для приёмки нужны две подписанные release-сборки с разными версиями:
проверьте пропуск, установку с перезапуском, недоступную сеть и отказ при
повреждённой подписи. Само обновление установленных пакетов не проверяется unit-тестами.
