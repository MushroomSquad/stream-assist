# Направление дизайна панели — «студийный пульт в ночном эфире»

`docs/superpowers/plans/2026-11-03-rules-and-redesign.md`. Метод — навык `unslop`

## Аудит текущей панели (по `references/signs.md`)

Тяжёлого «слопа» нет (градиентов, свечений, эмодзи нет). Панель выглядит как голые формы браузера.
Пользователь попросил полный редизайн — делаем все проходы.

- Оболочка: узкая центрированная колонка `max-width:960px` (`+page.svelte`) — приложение не использует окно.
- Навигация: 7 вкладок-кнопок в рамках, активная — сплошная зелёная заливка (`nav .active`).
- Заголовки жирные (h1 25px bold, h2 22px bold), иерархия весом, а не размером/цветом.
- Подзаголовок «Музыка для вашего эфира» — устарел, приложение делает больше; не нужен вовсе.
- Длинные формы одной колонкой на всю высоту («Озвучка» ~2400px), поля одинаковой ширины 560px.
- Ползунок громкости — системный синий `input[type=range]`; прогресс — системный `<progress>`.
- Светлая тема по умолчанию; тёмная — зеркальная, зелёно-серая.
- Цвета прописаны прямо в `+page.svelte` и отдельных `<style>` (`#202020` в `Widget.svelte` и т. п.).
- Подсказки заканчиваются точкой («Очередь пуста. Новые заказы появятся здесь.»), кавычки „…“ вперемешку.
- Шрифт `system-ui` — никто не выбирал.
- Пустые состояния — просто строка текста.

## Направление

- **Продукт.** Пульт стримера: заказы зрителей за баллы канала становятся треками и озвученными фразами в OBS.
- **Характер.** Спокойный, точный, живой.
- **Мир.** Ночная эфирная студия: пульт, лампа ON AIR, тайм-код, шкала громкости.
- **Яркие моменты.** (1) «Сейчас»: обложка трека + тайм-линейка с делениями. (2) Voice Lab: волна голоса (существующий canvas в «Источниках» и плеер рендеров — в цвете акцента на графите).
- **Сигнатура.** Тэлли-огонёк: круглая точка 8px. Янтарная (`--accent`, с кольцом 3px `rgba(accent,.14)`) — «в эфире / активно / подключено к эфиру»; серая `--tally-off` — выключено; зелёная `--ok` — сервис подключён. Используется **только** для статусов: сервисы в меню, действие и триггер в «Правилах», текущий элемент в «Сейчас»/очереди озвучки, задания Voice Lab. Больше нигде.

## Токены (`src/app.css`, `:root`)

Тёмная тема по умолчанию; светлая не делается (в спеке оставлена на усмотрение — решено: только тёмная, `color-scheme: dark`).

| Токен | Значение | Роль |
|---|---|---|
| `--bg-deep` | `#0f0f10` | боковое меню |
| `--bg` | `#141415` | фон страницы |
| `--card` | `#19191b` | карточки |
| `--raised` | `#232325` | поля ввода, активная строка, строки триггеров, вторичные кнопки |
| `--line` | `rgba(237,237,237,.08)` | все разделители и рамки |
| `--line-strong` | `rgba(237,237,237,.16)` | пунктир «+ Триггер», рамка поля в фокусе-ховере |
| `--t1` | `#ededed` | основной текст |
| `--t2` | `#a1a1a6` | вторичный текст, иконки |
| `--t3` | `#85858b` | мета, подписи, моно-цифры второго плана |
| `--accent` | `#f2a33a` | янтарь: тэлли «в эфире», включённые переключатели, сыгранная часть линейки, фокус |
| `--accent-ink` | `#1a1206` | текст/ручка на янтаре |
| `--tally-off` | `#3a3a3d` | выключенный огонёк и трек переключателя |
| `--ok` | `#4cc38a` | подключено, успех |
| `--err` | `#e5484d` | ошибки |
| `--warn-bg` | `rgba(242,163,58,.08)` | фон плашки-предупреждения (с рамкой `--line`) |
| `--primary-bg` / `--primary-ink` | `#ededed` / `#141415` | главная кнопка (off-white), `box-shadow: inset 0 1px 0 rgba(255,255,255,.4)` |
| `--ease` | `cubic-bezier(.22,1,.36,1)` | единственная кривая |
| `--fast` / `--mid` / `--slow` | `140ms` / `200ms` / `360ms` | ховер / меню и раскрытие / появление |

Контраст: `--t3` на `--card` ≈ 4.9:1; `--accent-ink` на `--accent` ≥ 9:1; `--primary-ink` на `--primary-bg` ≥ 15:1.

**Отступы:** шкала 4 — 4, 8, 12, 16, 20, 24, 32, 40, 48. Внутри контролов 8–12, строки списков — без зазора с разделителем или зазор 6, между группами 16–24, между секциями 32.

**Радиусы:** контролы и строки 8–10, карточки 16 (padding 20), окно-обложка 10, переключатель 9 (половина высоты 18), огонёк 50%.

**Тип:** IBM Plex Sans (интерфейс) + IBM Plex Mono (цифры: время, баллы, кулдауны, счётчики, номера в очереди, URL, метка). Веса 400/500, 600 только для названия продукта в меню. `font-variant-numeric: tabular-nums` у моно.

| Роль | Размер / интерлиньяж | Вес |
|---|---|---|
| мета, моно-цифры, подписи полей-подсказок | 12 / 16 | 400 |
| вторичный текст, строки меню статусов | 13 / 20 | 400 |
| основной текст, поля, пункты меню | 14 / 20 | 400 (пункт меню активный — `--t1`) |
| заголовок карточки | 16 / 22 | 500 |
| заголовок страницы | 20 / 28 | 500 |
| название трека в «Сейчас» | 28 / 1.1 | 500 |

Без uppercase-лейблов, без курсива, без отрицательного трекинга.

**Шрифты (`static/fonts/`, OFL, лицензии рядом):** `ibm-plex-{sans,mono}-{latin,cyrillic}-{400,500,600}-normal.woff2`. `@font-face` на каждое начертание и подмножество с `font-display: swap` и диапазонами:
- latin: `U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0304,U+0308,U+0329,U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD`
- cyrillic: `U+0301,U+0400-045F,U+0490-0491,U+04B0-04B1,U+2116`

**Иконки:** inline SVG в стиле lucide, 16px, `stroke-width:1.5`, `stroke: currentColor`, `fill:none`, цвет `--t2` (активный пункт — `--t1`). Набор иконок — один компонент `src/lib/Icon.svelte` (`name` → путь). Без пакета.

**Глубина:** только ступени поверхностей и линии. Тень — только у всплывающего (меню/подтверждение): `0 8px 24px rgba(0,0,0,.4)`.

**Движение:** ховер — смена фона/цвета за `--fast`; нажатие — `scale(.98)`; раскрытие «Настройки и лимиты» — opacity + `translateY(4px)` за `--mid`; переход между разделами — без анимации. Никаких циклических анимаций, кроме огонька задания «идёт» в Voice Lab — нет, и он статичен. Переходы только `color, background-color, border-color, opacity, transform`.

## Оболочка

- Сетка: боковое меню 240px (`--bg-deep`, рамка справа `--line`, padding 16/12) + контент (padding 24/32, `max-width: 1280px`, слева выровнен). Окно уже 900px — меню сворачивается до 56px (только иконки, подписи в `title`/`aria-label`).
- Меню сверху: знак (кольцо 14px с точкой, `--t2`) + «Stream Assist» 16/600. Пункты 34px, зазор 2, иконка + подпись, активный — `--raised` + `inset 0 1px 0 rgba(255,255,255,.06)`. Порядок: Сейчас · Правила · Виджет · Подключения · Voice Lab.
- Меню снизу (над линией `--line`): статусы сервисов строками 28px с огоньком — «Twitch», «Spotify», «OBS» (зелёный — подключён, серый — нет; янтарный — Twitch подключён **и** есть активная награда/метка). Клик ведёт в «Подключения». Данные: `twitch_status`, `spotify_status`, `obs_check` уже есть в `api.ts`; опрос — при монтировании и раз в 30 с.
- Заголовок страницы: 20/500 слева, справа моно-мета 12 `--t3` (например, «очередь 3»).
- Уведомления (`notice`): плашка `--warn-bg` с рамкой `--line`, радиус 10, текст `--t1`; ошибки — текст `--err`.

## Экраны

- **Сейчас.** Карточка «деки»: обложка 168×168 r10 (нет обложки — графитовый квадрат с иконкой ноты `--t3`), справа: огонёк + «В эфире · Spotify/YouTube» 12 `--accent`; название 28/500; исполнитель 15 `--t2`; «Заказал **ник**» 13 `--t3`; тайм-линейка (деления 1px через 6px, сыгранное — `--accent`, остальное `--t1` 14%, указатель 2px `--t1`); время моно 12; кнопки «Пропустить» (primary), «Пауза»/«Продолжить», «Вернуть очередь» (когда есть); громкость — собственный трек 4px (`--t2` заполнено, `#2c2c2f` фон) на нативном `input[type=range]` со стилями, число моно. Очередь — строки 44px: № моно `--t3`, «**Трек** · исполнитель», зритель `--t2`, длительность моно справа; перетаскивание как сейчас, ховер строки — `--raised`, кнопка удаления появляется на ховере/фокусе. Пусто: «Очередь пуста» `--t2` + «новые заказы появятся здесь» `--t3`, без точки.
- **Правила.** Как в макете (раскладка A): карточка действия — огонёк, заголовок 16/500, переключатель справа; строки триггеров 44px на `--raised` r10: огонёк, вид (13 `--t3`, колонка 120), параметры (название 500 / метка моно), моно-мета («500 баллов · кд 0 с»), переключатель, «Изменить» (текст-кнопка `--t3`); выключенный триггер — параметры на 50% прозрачности; ошибка — строка 12 `--err` под триггером. «+ Триггер» — пунктир `--line-strong` r10 36px. Низ карточки — раскрывашка «Настройки и лимиты» с моно-сводкой справа. Внутри — формы в две колонки (≥ 1100px), поля 36px на `--raised`. Очередь/URL/тест озвучки — второй раздел в карточке «Озвучка» под раскрывашкой «Очередь и виджет».
- **Виджет.** Слева форма (тема, порт, масштаб), справа живое превью темы (существующий iframe на подложке `#202020` — единственное исключение из токенов) и URL-ы источников моно с кнопкой «Копировать» рядом.
- **Подключения.** Три карточки сервисов в столбик: огонёк + название + состояние; действия справа.
- **Voice Lab.** Подвкладки — сегментированный переключатель на `--raised` (не кнопки в рамках); канвасы/аудио на `--card`; волна и прогресс — `--accent`; статусы заданий — огонёк.

## Тексты

Без восклицаний, без точек в коротких строках и кнопках, «ё» как сейчас, кавычки «ёлочки». Убрать подзаголовок «Музыка для вашего эфира». Названия разделов — как в меню.
