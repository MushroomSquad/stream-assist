# Озвучка стрима (TTS) — спецификация

Статус: черновик к ревью · 2026-11-03 · ветка `feat/voice-lab` (нужен Voice Lab P0)

## Цель

Стример включает озвучку голосом из Voice Lab: зрители заказывают её наградой за баллы канала, сообщением
в чате с меткой или обоими способами. Звук идёт отдельным источником в OBS. Спам сдерживается настраиваемыми
лимитами.

## Решения пользователя (2026-11-03)

- Чат: озвучивается текст **до** метки; метка по умолчанию `%`, настраивается. Сообщение без метки — не озвучивается.
- Вывод: отдельный браузерный источник OBS (как YouTube-плеер музыки).
- Голос: один, выбирается в настройках из профилей Voice Lab.
- Настраиваемые лимиты: кулдауны (общий и на зрителя, только чат), кто может из чата (роли), фильтр ссылок
  и эмоутов, стоп-слова. Кнопки «Пропустить» и «Очистить очередь».
- Длина и размер очереди не настраиваются: жёсткие пределы 300 символов и 20 элементов.

## Объём

1. **Режимы.** Две независимые галочки: «Награда» и «Чат». Обе выключены по умолчанию.
2. **Награда.** Своя награда Twitch (по умолчанию «Озвучить текст», 300 баллов, ввод обязателен), создаётся и
   находится так же, как музыкальная (`find_manageable_reward` → `create_reward`), id хранится в настройках.
   Выключение режима → `is_enabled: false` у награды; включение → `true`. Название/цена/кулдаун меняются
   из панели (`update_reward`). При выходе из программы награда ставится на паузу, как музыкальная.
   Итог погашения: озвучено или пропущено стримером → `FULFILLED`; отклонено фильтром, очередь полна, синтез
   не удался, очередь очищена → `CANCELED` (баллы возвращаются).
3. **Чат.** EventSub `channel.chat.message` v1, условие `{broadcaster_user_id: я, user_id: я}`, скоуп
   `user:read:chat` (добавляется в `SCOPES`; старый токен без скоупа → предупреждение «Перелогиньтесь в
   Twitch» — только при включённом режиме «Чат», только на ответ 403; награды при этом работают).
   Подписка на чат делается всегда, когда Twitch подключён; включён ли режим «Чат», проверяет движок
   озвучки (переключение галочки не переподключает EventSub). Сообщения из общего чата другого канала
   (`source_broadcaster_user_id` задан и не равен моему id) игнорируются.
4. **Метка.** 1–3 непробельных символа. Берётся первое вхождение метки, перед которым не цифра (чтобы
   «на 100% согласен» не срабатывало); текст до него, `trim`. Пусто → игнор.
5. **Кто может (чат).** Галочки: все, сабы (badge `subscriber` или `founder`), VIP (`vip`), модераторы
   (`moderator` или `lead_moderator`). Стример (`broadcaster`) может всегда и не подчиняется кулдаунам.
6. **Кулдауны (чат).** Общий (по умолчанию 10 с) и на зрителя (60 с), 0 = выкл. Отсчёт с момента принятия
   сообщения в очередь (отклонённое фильтром или из-за полной очереди кулдаун не тратит). Сообщение в кулдаун молча игнорируется. Награды кулдаунами программы не
   ограничиваются (у Twitch-награды свой кулдаун).
7. **Фильтры (оба источника).** Эмоуты из чата вырезаются всегда (фрагменты `emote`); если после этого
   текста нет — игнор (награда — `CANCELED`). «Вырезать ссылки» (вкл. по умолчанию): токены с `://`,
   начинающиеся с `www.`, или вида `слово.слово[/…]` с последней меткой из ≥2 букв. Повтор одного символа
   длиннее 3 сжимается до 3. Стоп-слова — подстрока без учёта регистра → отклонить целиком. Затем текст
   обрезается до 300 символов по границе слова.
8. **Очередь.** До 20 элементов (текущий не считается). Полная → чат игнор, награда `CANCELED`.
   Порядок — FIFO. Элемент: id, источник (чат/награда + ref), логин, текст.
9. **Синтез.** Голос = `profile_id` из настроек, язык (по умолчанию `ru`, выбор из языков Voice Lab),
   скорость 0.7–1.5 (1.0), качество 8. Синтезируется по одному элементу перед воспроизведением, в
   `voice-lab/tmp/tts/<id>.wav`, **без** записи в «Рендеры». Слот синтеза Voice Lab занят (пользователь
   рендерит в панели) → ждём и пробуем раз в 1 с до 60 с, затем отказ. Обратное тоже верно: пока идёт
   синтез озвучки (~2–4 с), рендер в панели Voice Lab получает «занято». Голос не выбран / удалён / модель
   не установлена → элементы отклоняются сразу при приёме, в панели предупреждение.
   «Пропустить» во время синтеза: элемент считается пропущенным, результат синтеза выбрасывается.
10. **Воспроизведение.** Страница `/widget/tts` (без темы, прозрачная) подключается к `/ws?role=tts`,
    получает `TtsPlay { id }`, играет `/tts/<id>.wav`, отвечает `ended`/`error`. Один активный
    источник (новое подключение вытесняет старое, как у плеера музыки). Нет подключённого источника →
    очередь ждёт, панель показывает «Источник OBS не подключён». Страховка: нет ответа за
    `длительность + 10 с` → следующий (засчитывается как озвученное). WAV удаляется после окончания,
    аудио отдаётся с `Cache-Control: no-store`.
11. **Панель: вкладка «Озвучка».** Настройки (режимы, голос, язык, скорость, награда, метка, роли,
    кулдауны, фильтры, стоп-слова), адрес источника и кнопка «Добавить в OBS» (браузерный источник
    «Stream Assist — Озвучка», 400×100, звук через OBS, мониторинг и вывод), очередь с текущим элементом,
    «Пропустить», «Очистить очередь», «Проверить» (озвучить тестовую фразу вне лимитов).
12. **Перезапуск.** Очередь в памяти. При старте и после переподключения EventSub все `UNFULFILLED`
    погашения TTS-награды, которых нет в очереди и которые ещё не обработаны, → `CANCELED` (пропущенные
    за время разрыва возвращаются, а не озвучиваются). Повторно доставленное погашение не озвучивается
    дважды. При выходе и выходе из Twitch TTS-награда ставится на паузу; при подключении — снимается
    с паузы, если режим включён, иначе `is_enabled: false`.
13. **Названия наград** музыки и озвучки должны различаться.

## Не цели

- Голос на выбор зрителя, разные голоса для ролей.
- Приглушение музыки во время озвучки (делается фильтром «Ducking»/компрессором в OBS).
- Постоянный процесс синтеза: каждый элемент — отдельный запуск воркера (задержка ~2–4 с). Вернуться,
  если задержка мешает.
- Чтение ников («user сказал: …»), озвучка подписок/донатов/рейдов.
- Модерация на стороне Twitch (удалённые модератором сообщения не отзываются из очереди) — для этого
  «Пропустить»/«Очистить».

## Известные ограничения

- Ответы самой программы в чат (о заказах музыки) приходят как сообщения стримера; если в названии
  трека есть метка не после цифры, текст до неё будет озвучен.

## Риски

- Ложные срабатывания метки «%» в обычной речи — смягчено правилом «не после цифры» и настраиваемой меткой.
- Конкуренция за слот синтеза с панелью Voice Lab — ожидание до 60 с.
- Старые токены без `user:read:chat` — явное предупреждение и кнопка перелогина.
