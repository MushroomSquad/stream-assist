# Voice Lab v1 (P0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вкладка «Голоса» в Stream Assist: установка Supertonic 3, импорт и разметка записей, клонирование голоса на CPU, импорт style JSON, микшер N профилей, превью/сравнение, экспорт — всё локально, без CUDA/Python.

**Architecture:** Изолированный Rust-модуль `src-tauri/src/voice_lab/` со своей SQLite-БД и каталогом `<app_data_dir>/voice-lab/`, команды `vl_*`, события `vl-job`/`vl-install`. Чистые части (валидация style JSON, микшер) тестируются без модели. Вся работа с ONNX (синтез и клонирование) — в одноразовом дочернем процессе того же бинарника (`--vl-worker`), с пониженным приоритетом и JSONL-протоколом: у крейта нет отмены, его `async`-синтез блокирует поток, а паника при `panic=abort` убила бы музыку. Фронт — Svelte-вью, общается id-шниками.

**Tech Stack:** как в v1 (Rust 1.93 edition 2024, Tauri 2, tokio, rusqlite bundled, reqwest 0.12 rustls, sha2, serde_json, thiserror, anyhow; SvelteKit + Svelte 5 + TS) плюс `supertonic3-tts = "=1.3.0"` (тянет `ort 2.0.0-rc.*`, `ndarray 0.17`, `hound`, `cpal`), `ndarray = "0.17"`, `hound = "3.5"`, `libc = "0.2"` (только unix). Внешний `ffmpeg` — опционально в рантайме.

**Spec:** `docs/superpowers/specs/2026-11-02-voice-lab-design.md`

## Global Constraints

- Не менять музыкальную часть: `db.rs`, `driver.rs`, `player.rs`, `server/` — без правок; `app.rs` не трогать; `lib.rs` — `pub mod voice_lab;`, команды, вызов `voice_lab::init` в `.setup`; `main.rs` — перехват режима воркера.
- Модель: HF `Supertone/supertonic-3`, ревизия `3cadd1ee6394adea1bd021217a0e650ede09a323`, URL `https://huggingface.co/Supertone/supertonic-3/resolve/<rev>/<path>`. Каждый файл сверяется с SHA-256 из `MODEL_FILES`.
- Speaker encoder (опционально): `https://github.com/k2-fsa/sherpa-onnx/releases/download/speaker-recongition-models/3dspeaker_speech_eres2net_sv_en_voxceleb_16k.onnx` → `models/speaker-encoder/speaker_encoder.onnx`, SHA-256 — константа.
- ONNX только `Device::Cpu`; GPU-фичи крейта не включать. `ort` закреплён прямой зависимостью `ort = "=2.0.0-rc.13"` (rc.14+ ломает API крейта: `Session::builder` требует `&Environment`); не обновлять.
- Пути крейта: `supertonic3_tts::{Style, CloneOptions, CloneProgress, VoiceCloner, Device, AVAILABLE_LANGS, probe_bank_for, features}`, `supertonic3_tts::helper::{VoiceStyleData, StyleComponent, save_voice_style, load_text_to_speech_on, write_wav_file}`.
- Формы стиля: `style_ttl` `[1,50,256]`, `style_dp` `[1,8,16]`, `type` `"float32"`, все значения конечны, файл ≤ 2_097_152 байт (проверять размер до чтения).
- Аудио: файл ≤ 250 МБ, ≤ 30 мин; рабочая копия WAV mono s16 44100 Гц; регион клона 1000–15000 мс; фрагмент для прослушивания ≤ 60000 мс.
- Синтез: текст `trim().chars().count()` 1–1000, язык из `AVAILABLE_LANGS`, по умолчанию `ru`; скорость 0.7–1.5; качество 5–12, по умолчанию 8.
- Микшер: 1 ≤ N ≤ 8, профили без повторов, веса конечные, 0 ≤ w ≤ 100, сумма > 0; f64 внутри, f32 на выходе.
- Подпроцессы (`ffmpeg`, воркер) — `Command` с фиксированным списком аргументов, без shell; на Windows `creation_flags(CREATE_NO_WINDOW = 0x08000000)`; stderr → `Stdio::null()`.
- Фронт после импорта передаёт только id. Пути (абсолютные) принимают только `vl_import_audio`, `vl_import_profile`, `vl_export_*`.
- Ошибки команд — строка-код из спеки; тексты — `errorMessages` в `src/lib/i18n/ru.ts`.
- `std::sync::Mutex<Store>` не держать через `.await` и не держать во время копирования/декодирования/сети.
- В логи не писать транскрипты, тексты синтеза и тензоры.
- Каждая задача, создающая файл в `voice_lab/`, добавляет `pub mod <имя>;` в `src-tauri/src/voice_lab/mod.rs`.

## Review Focus

1. **Отмена клона, падение воркера, выход приложения посреди работы** → профиля нет, статус `cancelled`/`failed`, процесс мёртв, `tmp` чист; после выхода приложения воркер сам умирает по EOF stdin. Тесты `cancel_kills_worker`, `crashed_worker_fails_job`, `worker_exits_on_stdin_eof` (Task 6).
2. **Чужой/битый style JSON** (другие `dims`, `1e39` → inf, `1e999`, глубокая вложенность, 3 МБ, лишний `metadata`) → код ошибки, без паники, metadata не попадает в канон. Тесты Task 1.
3. **Смешивание далёких голосов** → строки остаются нормированными, тон не «проседает». Тест `mix_keeps_row_norms` (Task 2).
4. **Оборванное/подменённое скачивание модели** → файл не попадает в `models/`, повтор докачивает только недостающее. Тесты `checksum_mismatch_not_installed`, `install_skips_valid_files` (Task 4).
5. **Регион за пределами записи, стерео/48 кГц WAV, MP3 без ffmpeg, 8-часовой подкаст** → `REGION_INVALID` / корректная конвертация / `AUDIO_UNSUPPORTED` / `AUDIO_TOO_LONG` без гигабайтного WAV. Тесты Task 5.
