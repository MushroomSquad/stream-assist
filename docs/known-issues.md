# Открытые проблемы

## Сервер виджета не восстанавливается после временной занятости порта

Статус: исправлено в 0.4.2. Сервер повторяет bind раз в секунду, сохраняя порт и исходные каналы; предупреждение и доступность сервера обновляются автоматически. Обнаружено в 0.4.1 на Linux после обновления.

- При запуске записывается `server_port_busy` для порта `47821`.
- Позже порт свободен, работает один экземпляр Stream Assist, но сервер остаётся выключенным.
- `/debug` недоступен; виджеты OBS, воспроизведение YouTube и доставка озвучки не работают.
- Панель показывает «Сервер виджета не запущен». Временное решение — полностью закрыть приложение и запустить снова.

Для исправления: обеспечить восстановление после освобождения порта, проверить
перекрытие старого и нового процессов при обновлении и защиту от повторного запуска.
Не менять порт автоматически: URL источников OBS должны оставаться действительными.

Приёмка: занять порт перед запуском, затем освободить его; сервер должен запуститься,
панель должна снять предупреждение, `/debug` и существующие источники OBS — снова работать.
При длительно занятом порте приложение должно оставаться доступным и показывать причину.

## Spotify Web API принимает команды, но локальный клиент их не выполняет

Статус: для локального Spotify на Linux исправлено в 0.4.2 через MPRIS. Отказ управления через Web API остаётся внешним ограничением исследованной сессии.

- Ручное воспроизведение и локальная команда MPRIS `OpenUri` работают.
- Независимый от Stream Assist запрос Web API возвращает HTTP 204, но не запускает заказанный трек.
- API возвращает пустой трек и `is_playing=false`; после локального запуска чтение состояния синхронизируется.
- Проверены совпадение аккаунта, Premium, активное устройство, отсутствие private session и ограничения управления, доступность треков для рынка аккаунта.
- Перезапуск клиента, перенос воспроизведения и запрос без `device_id` не устранили проблему управления через Web API.

В 0.4.0 добавлена проверка фактического запуска перед выполнением награды; она предотвращает
ложное подтверждение, но не устраняет отказ самого управления. В 0.4.2 на Linux включён локальный режим MPRIS: все команды и опрос используют один плеер. Для удалённого устройства локальный режим отключается в «Подключениях» с перезапуском приложения.
